# 🎙 AudioCleanerPro

Автоматизированный инструмент для очистки подкастов от шума, удаления тишины и цензуры мата с генерацией SRT-маркеров.

## ✨ Возможности

-   **Адаптивное шумоподавление:** VAD-guided noisereduce — мягкая очистка на участках с речью (сохранение тембра), агрессивная на тишине
-   **Удаление тишины:** Silero VAD автоматически находит и убирает неречевые участки
-   **Цензура мата:** Замена на «МЯУ» или «БИП» с настраиваемым паддингом
-   **Умные фильтры «блин»:** Спектральный анализ резонанса «Л» + контекстная проверка соседей + фолбэк по длительности — слово «блин» не цензурится как «бля»
-   **SRT-маркеры:** Автоматическая генерация субтитров с точными таймкодами каждого зацензуренного слова
-   **Восстановление динамики:** Envelope restoration после шумоподавления для естественного звучания
-   **Многопоточность:** Параллельная обработка чанков (до 4 потоков, оптимизировано для 16 ГБ RAM)

## 📋 Требования

-   Windows 10/11 x64
-   Python 3.12+ (рекомендуется 3.12; 3.14 поддерживается, но некоторые пакеты могут требовать сборки из исходников)
-   ~4 ГБ свободного места на диске

> ⚠️ **Примечание по GPU:** Программа работает на CPU. AMD Radeon RX 580 не поддерживается для ускорения нейросетевого шумоподавления (требуется NVIDIA CUDA). На Intel Core i5-13400F обработка 3-часового подкаста занимает ~10–15 минут.
