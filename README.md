# 🎙 AudioCleanerPro

Автоматизированный инструмент для очистки подкастов от шума, замены неречевых участков тишиной и цензуры мата с генерацией SRT-маркеров.

## ✨ Возможности

-   **Адаптивное шумоподавление:** VAD-guided noisereduce — мягкая очистка на участках с речью (сохранение тембра), агрессивная на тишине
-   **Тишина:** Silero VAD находит неречевые участки и заменяет их тишиной; длительность файла сохраняется
-   **Цензура мата:** Замена на «МЯУ» или «БИП» с настраиваемым паддингом и плавными фейдами
-   **Поиск словоформ:** словарь `words.txt` + корни (`блять`, `нахуй`, `заебал`, `охуеть`, …), нормализация `ё → е` и белый список омографов (`блин`, `сукно`, `хутор`, `мудрый`, …)
-   **Защита от ложных срабатываний:** белый список омографов и порог уверенности Vosk
-   **SRT-маркеры:** Автоматическая генерация субтитров с точными таймкодами каждого зацензуренного слова
-   **Восстановление динамики:** Envelope restoration после шумоподавления, блоками по 30 с (низкий расход памяти)
-   **Многопоточность:** параллельное шумоподавление (до 4 потоков) и распознавание сырого аудио блоками по 20 с в несколько потоков — с прогрессом и ETA
-   **Экономия памяти:** чтение во `float32`, потоковая склейка чанков, без копий на весь файл

## 📋 Требования

-   Windows 10/11 x64
-   Python 3.12+ (рекомендуется 3.12; 3.14 поддерживается, но некоторые пакеты могут требовать сборки из исходников)
-   ~4 ГБ свободного места на диске

> ⚠️ **Примечание по GPU:** Программа работает на CPU. AMD Radeon RX 580 не поддерживается для ускорения нейросетевого шумоподавления (требуется NVIDIA CUDA). На Intel Core i5-13400F обработка 3-часового подкаста занимает ~10–15 минут.

## 🚀 Запуск на Windows

### Первый запуск (для пользователя)

1.  Дважды щёлкните **`install.bat`** — он найдёт Python 3.12+, создаст `venv`, установит зависимости и сделает ярлык `AudioCleanerPro` на рабочем столе.
2.  Дальше запускайте любым способом:
    -   ярлык **`AudioCleanerPro`** на рабочем столе — без окна консоли;
    -   **`run_app.bat`** — обычный запуск;
    -   **`AudioCleanerPro.vbs`** — тихий запуск без мелькания консоли;
    -   **`run_app.bat --console`** — запуск с консолью и сообщениями (для диагностики).

Проверить окружение без запуска приложения:

```bat
install.bat --check
run_app.bat --check
```

Если модели Vosk нет, `install.bat` подскажет ссылку на скачивание. Приложение всё равно запустится, но цензура будет отключена.

### Для разработки

```powershell
cd C:\Projects\AudioCleanerPro
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Для тестов:

```powershell
pip install -r requirements-dev.txt
```

Запуск из исходников:

```powershell
python app.py
```

## 🍎 macOS

Готовые сборки публикуются в GitHub Releases:

-   `AudioCleanerPro-3.8-macos-arm64.zip` — Apple Silicon (M1/M2/M3/M4);
-   `AudioCleanerPro-3.8-macos-x86_64.zip` — Intel Mac.

Требования: macOS 11+, Python не нужен. Распакуйте архив, перетащите `AudioCleanerPro.app` в `Applications` и запустите. При первом запуске неподписанного приложения macOS может показать предупреждение Gatekeeper: нажмите правой кнопкой по `AudioCleanerPro.app` → «Открыть» → «Открыть».

Настройки и журнал на macOS: `~/Library/Application Support/AudioCleanerPro`.

Сборка выполняется в GitHub Actions на реальных macOS-раннерах (`.github/workflows/build-macos.yml`), потому что собрать macOS-приложение на Windows нельзя. Запуск workflow: вкладка **Actions** → **Build macOS** → **Run workflow**. Локальная сборка на Mac:

```bash
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt pyinstaller
python -m PyInstaller --clean --noconfirm AudioCleanerPro-macos.spec
```

## 🗂 Где хранятся настройки и лог

-   Настройки: `%LOCALAPPDATA%\AudioCleanerPro\audio_cleaner_settings.json`
-   Лог: `%LOCALAPPDATA%\AudioCleanerPro\audio_cleaner.log` (ротация: 5 МБ × 3)

В режиме разработки лог пишется в корень проекта. Это сделано специально: установка идёт в `Program Files`, куда у обычного пользователя нет прав на запись.

## 🧠 Как работает цензура

1.  Vosk распознаёт **сырое** аудио (до нормализации и шумодава) блоками по 20 с в несколько потоков; в журнале видны процент и ETA. Так точнее, чем распознавать денойзнутое аудио или нарезку по VAD (проверено по WER).
2.  Слово нормализуется (`ё → е`) и проверяется по словарю `words.txt` и списку корней — так ловятся формы, которых нет в словаре (`блять`, `нахуй`, `заебал`).
3.  Отбрасываются омографы из белого списка (`блин`, `бляха`, `сукно`, `хутор`, …) и слова с уверенностью распознавания ниже 0.25.
4.  Найденные интервалы объединяются, на них накладывается «МЯУ»/«БИП» с фейдами, маркеры пишутся в SRT.

### Модель распознавания

По умолчанию используется `vosk-model-small-ru-0.22`. Приложение само найдёт модель в порядке приоритета:

`vosk-model-ru-0.42` → `vosk-model-ru-0.22` → `vosk-model-small-ru-0.22` → любая папка `vosk-model*`

Чтобы повысить точность, положите большую модель (`vosk-model-ru-0.42`, ~1.8 ГБ) рядом с `app.py` или в `_internal` рядом с EXE — код переключится автоматически.

## 🧪 Тесты

```powershell
python -m pytest -q
```

Покрыты: нормализация настроек, пороги пресетов, словарь/белый список, нормализация `ё → е`, поиск модели, склейка чанков (без провалов громкости), восстановление огибающей, SRT-таймкоды, нарезка речи на блоки распознавания, дедупликация слов на стыках и отмена.

## 🧩 Сборка релизной версии

### Сборка EXE

```powershell
cd C:\Projects\AudioCleanerPro
.\build_release.bat
```

Скрипт использует `venv\Scripts\python.exe` (если есть), собирает по `AudioCleanerPro.spec` и кладёт `words.txt` и модель Vosk внутрь `dist\AudioCleanerPro\_internal` — именно там PyInstaller 6 ищет ресурсы (`sys._MEIPASS`).

### Сборка установщика

Установите Inno Setup и откройте `AudioCleanerProInstaller.iss`, либо выполните:

```powershell
iscc AudioCleanerProInstaller.iss
```

После этого в папке проекта появится `AudioCleanerPro_Setup.exe`.

> Если папки модели нет в корне проекта, сборка завершится с предупреждением: положите `vosk-model-small-ru-0.22` (или большую `vosk-model-ru-0.42`) в `_internal` рядом с EXE перед установкой. Без модели приложение всё равно запустится (шумодав и замена тишины работают), но цензура будет отключена с предупреждением в журнале.
